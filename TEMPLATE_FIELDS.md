# TEMPLATE_FIELDS.md — Справочник плейсхолдеров для Word-шаблонов

Шаблоны `.docx` заполняются движком **docxtemplater**. В нужные места документа
вставляются метки в двойных фигурных скобках: `{{ключ}}`. При генерации система
подставляет в них данные абитуриента.

> Разделители именно двойные: `{{` … `}}` (одиночные `{ }` игнорируются — можно
> спокойно использовать обычные скобки в тексте).

---

## Как размечать документ

1. Открой бланк колледжа в Word.
2. Вместо места, куда должны попасть данные, впиши плейсхолдер из таблицы ниже.
   Пример: было «Фамилия: ____________» → стало «Фамилия: {{personal.lastName}}».
3. Сохрани как `.docx` и передай в проект (положим в `public/templates/`).

---

## Доступные плейсхолдеры

### Общие

| Плейсхолдер | Значение (пример)          |
| ----------- | -------------------------- |
| `{{fio}}`   | Иванов Иван Иванович       |
| `{{today}}` | 29.06.2026 (дата создания) |

### Колледж

| Плейсхолдер            | Значение                                    |
| ---------------------- | ------------------------------------------- |
| `{{college.name}}`     | ГБПОУ «Волгоградский технический колледж»   |
| `{{college.nameFull}}` | полное наименование                         |
| `{{college.address}}`  | 400001, г. Волгоград, ул. Козловская, д. 57 |
| `{{college.phone}}`    | (8442) 97-33-34                             |
| `{{college.inn}}`      | ИНН                                         |

### Личные данные (`personal`)

| Плейсхолдер                  | Значение                  |
| ---------------------------- | ------------------------- |
| `{{personal.lastName}}`      | Фамилия                   |
| `{{personal.firstName}}`     | Имя                       |
| `{{personal.middleName}}`    | Отчество                  |
| `{{personal.birthDate}}`     | 01.05.2008                |
| `{{personal.birthDateLong}}` | 1 мая 2008 г.             |
| `{{personal.birthPlace}}`    | Место рождения            |
| `{{personal.gender}}`        | мужской / женский         |
| `{{personal.snils}}`         | 123-456-789 00            |
| `{{personal.phone}}`         | +7 (999) 123-45-67        |
| `{{personal.email}}`         | email (может быть пустым) |

### Паспорт и адреса (`passport`)

| Плейсхолдер                        | Значение                              |
| ---------------------------------- | ------------------------------------- |
| `{{passport.series}}`              | Серия (4 цифры)                       |
| `{{passport.number}}`              | Номер (6 цифр)                        |
| `{{passport.seriesNumber}}`        | «1234 567890»                         |
| `{{passport.issuedBy}}`            | Кем выдан                             |
| `{{passport.issuedDate}}`          | Дата выдачи                           |
| `{{passport.divisionCode}}`        | Код подразделения                     |
| `{{passport.registrationAddress}}` | Адрес регистрации                     |
| `{{passport.actualAddress}}`       | Фактический адрес (или = регистрации) |

### Предыдущее образование (`education`)

| Плейсхолдер                     | Значение          |
| ------------------------------- | ----------------- |
| `{{education.institutionName}}` | Учебное заведение |
| `{{education.finishedYear}}`    | Год окончания     |
| `{{education.documentType}}`    | аттестат / диплом |
| `{{education.documentSeries}}`  | Серия документа   |
| `{{education.documentNumber}}`  | Номер документа   |

### Условия обучения (`conditions`)

| Плейсхолдер                      | Значение                            |
| -------------------------------- | ----------------------------------- |
| `{{conditions.specialty}}`       | Название специальности              |
| `{{conditions.specialtyCode}}`   | Код (09.02.07)                      |
| `{{conditions.educationForm}}`   | очная / заочная / вечерняя          |
| `{{conditions.baseEducation}}`   | 9 / 11                              |
| `{{conditions.foreignLanguage}}` | английский / немецкий / французский |
| `{{conditions.cipher}}`          | Шифр личного дела                   |
| `{{conditions.contractNumber}}`  | Номер договора (может быть пустым)  |
| `{{conditions.enrollmentYear}}`  | Год поступления                     |
| `{{conditions.fundingBasis}}`    | платная / бюджет                    |

### Родители / представители (`parents`)

По индексу:

| Плейсхолдер             | Значение                     |
| ----------------------- | ---------------------------- |
| `{{parent1.role}}`      | Мать / Отец / Опекун         |
| `{{parent1.fullName}}`  | ФИО                          |
| `{{parent1.phone}}`     | Телефон                      |
| `{{parent1.workplace}}` | Место работы / «Не работает» |
| `{{parent2.role}}` …    | вторая запись (аналогично)   |

Циклом (если в бланке таблица/список родителей):

```
{{#parents}}
{{role}} — {{fullName}}, тел. {{phone}}, {{workplace}}
{{/parents}}
```

## Условные блоки

docxtemplater поддерживает условия. Например, показать строку только если есть
номер договора:

```
{{#conditions.contractNumber}}Договор № {{conditions.contractNumber}}{{/conditions.contractNumber}}
```

---

## Чего пока нет

Если в твоих бланках встретятся поля, которых нет в списке выше (например, новые
сведения об абитуриенте) — их нужно добавить: в форму (`src/domains/applicant`),
в типы/схему и в `buildTemplateData.ts`. Отметь такие места — добавлю.
